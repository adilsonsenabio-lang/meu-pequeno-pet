Use o arquivo `IMPORTAR_NO_GITHUB.md` deste ZIP, que explica a importação inicial na branch `main` usando GitHub Desktop. Não execute `git init` nem `git push --force` em um repositório já existente.

https://adilsonsenabio-lang.github.io/meu-pequeno-pet/
