# Meu Pequeno Pet

Jogo infantil de bichinho virtual em pixel art. Projeto preparado para publicação como PWA no GitHub Pages, com instalação offline e atualizações pelo mesmo endereço.

**Situação:** migração inicial em andamento. Os arquivos completos do jogo ainda precisam ser enviados antes da ativação do site.

- Versão-base preparada: V84.23.
- Objetivo: preservar os 13 cenários, as animações, os cuidados com o pet e a compatibilidade com os dados salvos.
- Regras de manutenção: consulte `Agents.md`.

Após importar os arquivos do pacote V84.23, a pasta `web/` será o conteúdo hospedado no GitHub Pages. O workflow `.github/workflows/pages.yml` cuidará da publicação.
